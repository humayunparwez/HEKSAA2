# HEKSAA

Fresh static frontend prototype for Smart India Hackathon 2026, PS ID 26094.

## Structure

- `index.html` — landing/role selection
- `auth.html` — unified Patient/Doctor authentication UI
- `patient-dashboard.html` — patient workspace
- `doctor-dashboard.html` — professional workspace
- settings, help, about, privacy and 404 pages
- JavaScript uses localStorage for prototype data only

## Important

The current concern/risk indicators are demonstration heuristics, not clinically validated predictions or diagnoses.

Backend, real authentication, database synchronization, and validated AI/ML should be added before any production or clinical use.
